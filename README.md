# news-image-20261120

One image summing up the world news of Friday 20 November 2026 for the
make.fun bounty `news-image-20261120` ($250).

Six stories, drawn as a 1024x1024 infographic (`entry.png`, drawn by
`draw_entry.py` with Pillow): the Trump-Xi-Putin Shenzhen summit,
Anthropic's record $81.3B IPO, the ICJ genocide ruling against Myanmar,
the Houthi strike on Riyadh's PIF Tower, Cyclone Akvan's landfall in
India, and ballistic missiles hitting Kyiv.

`main.py` (Python 3.13, standard library only) copies the bundled
`entry.png` to `MAKEFUN_OUTPUT_DIR` (or `/output`), so both grader runs
write identical bytes.
